# 每日 AI 早报生成规范（Skill）

## 目标

每天早上 08:30（Asia/Shanghai）自动执行一次，产出高质量、去水文、通俗易懂的单文件 HTML 早报，按 `AI早报-YYYYMMDD.htm` 保存至 `news/` 目录，浏览器打开即可离线阅读。

## 执行步骤

### 1. 信息采集（过去 24 小时）
通过联网搜索覆盖以下两类信息源：
- **AI 前沿动态**：大模型发布与重要更新、顶会/核心研究突破、主流 AI 工具或 Agent 框架发布、行业关键标准与基础设施动向。
- **GitHub Trending 热门开源项目**：聚焦 AI / LLM / Agent / MCP / 开发者工具方向的高增速开源仓库。

### 2. 筛选与去噪原则
- **严格过滤**：标题党、营销软文、无实质内容的搬运/二手翻译、纯融资公关稿、无代码/无实验支撑的空泛概念。
- **精选 5 条**：兼顾前沿行业动态与 GitHub 热门开源项目，确保每条都有明确的技术增量或实用价值。

### 3. 内容撰写要求
每条精选必须包含以下字段：
- **标题（title）**：简洁醒目，一眼看懂核心事件。
- **分类标签（category）**：从 `行业动态`、`开源模型`、`技术突破`、`开源项目`、`工具生态` 中选取。
- **来源标注（source）**：机构或仓库名称（如 `OpenAI`、`obra / superpowers`）。
- **核心亮点（highlight）**：用大白话讲清楚它是什么、做了什么、有哪些关键数据或能力。
- **技术价值（value）**：讲清楚为什么值得关注、解决了什么痛点、对开发者或行业的实际意义。
- **原始链接（url）**：真实、有效、可点击跳转的原始出处或 GitHub 仓库链接。

### 4. 页面渲染与保存
- 风格规范：简约浅色卡片风（米白浅灰底色 + 纯白圆角卡片 + 柔和阴影 + 分类筛选标签 + 响应式排版），所有 CSS/JS 内联在单文件中，无任何外部依赖。
- 参考模板：`code/template.htm`
- 渲染脚本：`code/generate_briefing.py`（支持传入结构化 JSON 直接渲染输出）
- 输出路径：`news/AI早报-YYYYMMDD.htm`（`YYYYMMDD` 为当天本地日期）
