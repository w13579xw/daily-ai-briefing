01 行业动态
OpenAI / 行业基准

OpenAI 首次公开内部预训练“困惑度”曲线，呼吁全行业设立安全红线

核心亮点

OpenAI 首席科学家 Jakub Pachocki 发表长文《Perplexity and Intelligence》，首次亮出从 GPT-3.5（~0.99）、GPT-4（~0.91）一路降到当前前沿模型（~0.76）的内部预训练对数困惑度（log-perplexity）进度，并透露降到 ~0.76 后模型已能攻克数学领域的长期未解难题。文章发布后，微软 AI 负责人迅速晒出自家 MAI-2 Base 的 0.819 成绩单，Google DeepMind 等机构也随之展开公开讨论。

技术价值

以前行业习惯拿“训练算力（FLOPs）”划安全红线，但算法提效让算力门槛越来越失真。用各家都能复现的交叉熵损失/对数困惑度当“能力测速仪”，既给预训练缩放律提供了公开对照坐标，也让 AI 安全治理从口号走向了可量化的工程标准。

02 开源模型
AWS Strands Labs

AWS 开源 Strands Decider v2：基于 Gemma 4 的 Agent 专用“决策模型”家族

核心亮点

AWS Strands Labs 基于 Google Gemma 4 架构开源了 5 个尺寸（E2B、E4B、12B、26B-A4B MoE、31B）的专用决策模型，全部采用 Apache 2.0 协议。它不像普通大模型那样逐字生成长文本，而是在单次前向推理中直接给出一组预设选项的校准概率，还能主动回答“我不确定”，专攻工具路由、参数校验、工单分流和安全护栏。

技术价值

很多团队现在用昂贵的旗舰模型去干“二选一、做路由”的脏活累活，既慢又烧钱。AWS 实测用决策模型替换通用大模型后，标注与推理成本最高直降 98%、延迟缩短 78%，为生产环境落地“小决策模型管路由 + 大模型管深度推理”的混合 Agent 架构提供了现成的开源方案。

05 GitHub 热门
HKUDS / CLI-Anything

HKUDS/CLI-Anything 爆火：一键把传统桌面和网页软件变成 Agent 原生命令行

核心亮点

香港大学数据智能实验室（HKUDS）推出的热门开源项目，专门把那些原本没有 API 的传统桌面软件和常规应用，自动包装成结构化、对大模型友好的命令行接口（CLI），让终端型和编程型 Agent 可以像执行普通命令一样直接操控各种外部软件。

技术价值
